# Dice Game — Solana On-Chain Betting

A provably fair dice betting game built on Solana using the Anchor framework. Players bet SOL on dice roll outcomes, with randomness generated by the house signing bet data using Ed25519 — verifiable entirely on-chain.

---

## How It Works

1. **House initializes** a vault (PDA) and deposits SOL to fund payouts.
2. **Player places a bet** — picks a target roll (1–99) and an amount (min 0.1 SOL).
3. **House signs** the serialized bet data with their Ed25519 private key.
4. **Player submits** the signature on-chain to resolve the bet.
5. The signature is SHA-256 hashed to derive the actual roll (1–100).
6. **If player's target roll > actual roll**, they win — payout is sent from the vault.
7. **If the bet is never resolved**, the player can reclaim their stake via a refund.

The house edge is **1.5%** (150 basis points). Fairness is enforced by Solana's native Ed25519 signature verification program — no trusted oracle needed.

---

## Program Instructions

| Instruction                     | Actor  | Description                                     |
| ------------------------------- | ------ | ----------------------------------------------- |
| `initialize(amount)`            | House  | Creates and funds the vault PDA                 |
| `place_bet(seed, roll, amount)` | Player | Locks a bet on-chain and transfers SOL to vault |
| `resolve_bet(sig)`              | Player | Submits house signature; pays out or forfeit    |
| `refund_bet()`                  | Player | Recovers stake from an unresolved bet           |

---

## Payout Formula

```
payout = (bet_amount × (10,000 − 150)) / (roll − 1) / 100
```

Example — betting 0.1 SOL on roll 50 (wins if actual roll < 50):

- Winning outcomes: 49
- Payout ≈ 0.201 SOL

Higher roll = lower win chance = higher payout.
